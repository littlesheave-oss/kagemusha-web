戦うのは人ではなく、あなたが書いたコード。
一度置いておけば、あなたが寝ている間も、影武者が代わりに戦い続けます。

遊ぶ

将棋 SHOGI 持ち駒・成り・二歩・詰みまで判定。真上から見る2D盤。 開く → リバーシ REVERSI 最初に書くならこれ。合法手・パス・終局まで。 開く → チェス CHESS 立体盤。キャスリング・アンパッサン・千日手まで。 開く →

やり方

  1. ゲームを開く。ダウンロードも登録もいりません。そのままブラウザで動きます。
  2. サンプル戦略同士を戦わせて、動きを見る。ランダム・貪欲・角優先の3種が入っています。
  3. 「マイ影武者」で自分のコードを書く。bot(...) を1つ書くだけ。自動テストに通れば保存できます。
  4. サンプルや自分の別バージョンと戦わせる。勝てるようになったら、サーバーに登録して他の人の影武者に挑みます。

影武者の書き方

// リバーシの例。提示された合法手から1つ選んで返すだけ。
function bot(board, player, legalMoves) {
  // 角が取れるなら取る
  const corners = [[0,0],[0,7],[7,0],[7,7]];
  for (const m of legalMoves) {
    if (corners.some(c => c[0] === m.r && c[1] === m.c)) return m;
  }
  // なければ最初の合法手
  return legalMoves[0];
}

ゲームごとに引数は少し違いますが、どれも「渡された合法手の中から1つ返す」だけです。 返す値がおかしかったり、エラーで落ちたり、時間切れになった場合は、 安全側（ランダムな合法手）に倒して対局は続きます。棋譜にはその印が残ります。

知っておいてほしいこと

コードはあなたのブラウザに保存されます マイ影武者はこの端末の中だけに残ります。書き出し・読み込みもできます。
サーバー対戦は隔離した中で動かします 登録されたコードは、外に一切つながらない独立した実行環境で、時間とメモリの上限つきで動きます。
レーティングは1500から 1回の挑戦で先後を入れ替えた2局。勝てば上がり、負ければ下がります。
